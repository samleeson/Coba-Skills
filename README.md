# Coba Skills

User-created Grok Bot skills for Coba Research

Each folder is a skill with a `SKILL.md` in the [universal format](FORMAT.md): frontmatter `name` + `description`, then `# Title`, `## When`, `## Do`, `## Output`, `## Never`.

Live copies live at `/home/box/agent-data/workflows/<slug>/SKILL.md` and should match this repo.
