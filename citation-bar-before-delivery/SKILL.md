# Citation Bar Before Delivery

## When

- Before the first delivery of any research review, ED memo, or investor package that names people
- Before shipping a domain review or champion-facing brief that lists candidates by name
- Any time a draft has bare person names without citation lines

## Do

1. Scan every person name in the draft.
2. Gap-fill any missing citation with a real primary or reputable source in the form `Person — URL` (or filing / firm page / reputable press equivalent).
3. If you cannot find a source, mark `Person — unknown (needs source)` and keep the gap visible — do not invent a URL.
4. Only then deliver.

## Output

Every named person has a citation line (`Person — URL` or explicit unknown); no bare names on first delivery.

## Never

- Ship a first pass with bare names and promise citations later
- Fabricate URLs or quote attributions
