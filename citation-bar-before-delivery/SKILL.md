# Citation bar before first delivery

Use before the first delivery of any research review, ED memo, or investor package that names people.

## Bar

Every named person in the deliverable must have a citation line:

`Person — URL` (or filing / firm page / reputable press equivalent)

## Before you send

1. Scan every person name in the draft.
2. Gap-fill any missing citation with a real primary or reputable source.
3. If you cannot find a source, mark `Person — unknown (needs source)` and keep the gap visible — do not invent a URL.
4. Only then deliver.

## Never

- Ship a first pass with bare names and promise citations later.
- Fabricate URLs or quote attributions.
