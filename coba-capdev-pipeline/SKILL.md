# COBA CapDev pipeline

## When

- Running any COBA CapDev research project from scout through final package
- Handing off between CapDev bots or deciding who owns the next step
- Final Versions (or anyone) is about to push a finished pack to Manager

## Do

1. **Hunter** — scout / prelim cards (Person — URL; novelty dedupe).
2. **Researcher** — deepen (mandate, comps, check-band evidence; no invented AUM/emails/warm paths).
3. **Reviewer** — fact-check + HARD must-fixes / MERGE-NOTES (no re-scout).
4. **Editor** — bake HARD fixes into presentation-ready packs.
5. **Final Versions** — one-pagers / tier PDF package.
6. **Human (Samson)** — review; **explicit consent required** before Manager.
7. **Manager** — ingest / KB only **after** human consent.

**Final Versions consent gate (HARD):** After the PDF/package is ready, ask Samson before any push to Manager. Do not send Manager a final product until Samson says yes (widget or clear chat yes). If Samson declines or is silent, stop at Human. Consent covers that named deliverable only; a later revision needs consent again.

**Champions / framing:** Warm paths and ask framing through CapDev champions only (Memphis Orion, Eleanor Evans Medina, Adam Lerner, Dave Payne + evidenced network). Never list Samson as champion or as talking to FO/investor targets.

## Output

A CapDev project that has passed every stage in order, with Manager receiving finals only after Samson’s explicit consent.

## Never

- Skip Reviewer before Editor/Final Versions on researched packs
- Push finals to Manager without Samson’s consent
- Invent AUM, emails, warm paths, or raise totals
- Treat gatekeepers (Caprock-class MFOs) as LP NEW fills
- List Samson as a CapDev champion or frame him talking to investor/FO targets
