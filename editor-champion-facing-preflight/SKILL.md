# Editor champion-facing preflight

Use when Editor (or any COBA pack rewriter) delivers a champion-facing or presentation-ready brief / Tier package.

## Strip before send

Remove internal framing that is not for the champion:

- who created the doc / when / for which internal pass
- “framing notes,” meta intros, pipeline breadcrumbs (Hunter → Reviewer → Editor)
- editor change-logs meant for Samson unless he asked for a redline

Lead with the substance: thesis, candidates, Why-Fit, asks.

## Keep

- ED labels and evidence the champion needs
- citations and confidence when they help the pitch
- unresolved gaps only if they affect the ask

## Never

- Ship a presentation-ready ask with a who/when intro paragraph
- Leave internal metadata in the champion-facing PDF or brief
