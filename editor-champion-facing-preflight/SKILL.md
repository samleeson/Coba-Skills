# Editor Champion-Facing Preflight

## When

- Editor (or any COBA pack rewriter) delivers a champion-facing or presentation-ready brief / Tier package
- Before sending a pitch PDF or brief meant for the champion (not Samson’s redline)
- Any draft that still carries pipeline breadcrumbs or who/when intros

## Do

1. Strip internal framing that is not for the champion:
   - who created the doc / when / for which internal pass
   - “framing notes,” meta intros, pipeline breadcrumbs (Hunter → Reviewer → Editor)
   - editor change-logs meant for Samson unless he asked for a redline
2. Lead with the substance: thesis, candidates, Why-Fit, asks.
3. Keep ED labels and evidence the champion needs; keep citations and confidence when they help the pitch; keep unresolved gaps only if they affect the ask.

## Output

Champion-facing brief/PDF that leads with substance and has no who/when intro or internal pipeline metadata.

## Never

- Ship a presentation-ready ask with a who/when intro paragraph
- Leave internal metadata in the champion-facing PDF or brief
